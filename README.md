# YGO CDB 编辑器（Android）

用于在手机上浏览和编辑游戏王 `.cdb` 卡库，也可以在电脑浏览器中预览。界面由 `www/` 中的 HTML、JavaScript 和 CSS 实现；`sql.js` 在本地 WebView 中读写 SQLite，Android 外壳由 Capacitor 提供。日常编辑不依赖 `server.py`。

公开仓库提供源码，不分发游戏卡库数据。构建前需自行准备有权使用的 `.cdb`，放到 `www/cards.cdb`；系列码中文名称可从自己使用的游戏 `strings.conf` 生成。资源准备步骤见 [BUILD.md](BUILD.md#更新内置卡库与系列码名称)。

## 从哪里开始

- **安装或重新打包 Android 版**：看 [BUILD.md](BUILD.md)。仓库已有 `android/` 工程。
- **只预览网页界面**：在本目录运行 `npm start`，打开 `http://127.0.0.1:8137`。该命令实际使用 Python HTTP 服务器；不要直接用 `file://` 打开 `www/index.html`，因为页面需要加载本地 WASM 和卡库资源。
- **更新系列码中文名**：游戏 `strings.conf` 变化后，按 [名称表更新步骤](BUILD.md#更新内置卡库与系列码名称)重新生成并打包。手机 App 的 `www/setnames.js` 是构建时的快照，不会直接读取电脑上的 `strings.conf`。

## 在 App 中编辑

启动时会打开打包在 `www/cards.cdb` 中的卡库。如果曾通过「＋ → 导入官方卡库…」导入过卡库，Android 会优先使用保存在 App 私有目录中的那份；它在重启后仍生效。上方页签可在内置库、打开的文件和新建文件之间切换。

1. 用顶部「打开」选择外部 `.cdb`，或用「新建文件」创建空库。新建库先存在内存里。
2. 在搜索框按卡名或描述查找，用下拉框按卡片种类和子类筛选。点卡片查看，再点「编辑」修改；底部「＋」可新建卡片。
3. 编辑表单中的系列码最多四格，数字框使用十进制。下方检索框支持中文系列名、十进制和 `0x` 十六进制代码，例如 `妖精传姬` / `475` / `0x1DB`。点结果会填入当前目标格。
4. 编辑卡片后，点击顶部「保存cdb」导出**当前页签的完整卡库**。Android 会弹出系统“另存为”窗口；浏览器预览版会下载 `.cdb` 文件。

编辑、新建和删除先作用于内存中的当前文档。页签名称后的 `*` 表示有尚未保存的修改；关闭有修改的页签时会提示确认。**Android 的“保存cdb”目前是另存为，打开的原文件不会自动被覆盖。**请以系统保存窗口中实际选定的目标文件为准；当前实现取消保存窗口后也可能清除页签上的 `*`，此时修改仍留在内存中。

顶部「导出」会生成 `cards-export.json`，内容是**当前列表已加载的卡片**，受搜索、筛选和分页状态影响，不等同于完整卡库备份。需要完整卡库时使用「保存cdb」。卡片详情里的「导出cdb」会把该卡单独导出为 `c <卡密>.cdb`。

## 卡库来源和卡密查重

「＋」菜单中还有这些入口：

| 入口 | 作用 |
| --- | --- |
| 内置卡库 | 切回当前内置页签；导入过官方卡库时，该页签使用导入的版本 |
| 导入官方卡库… | 选取并校验一份 `.cdb`，保存到 Android App 私有目录，之后启动优先使用 |
| 选择库文件夹… | 授权一个文件夹，供新卡密查重，并作为打开/另存为窗口的默认位置 |
| 刷新卡库 | 重新读取已选文件夹中的 `.cdb` 卡密 |
| 卡密范围… | 调整随机新卡密的闭区间；默认 `900000000–900099998` |

新卡片的卡密会对照内置库、所有已打开文档，以及已选文件夹中直接列出的 `.cdb` 检查重复。文件夹扫描只列出该目录的直接子文件，不递归进入子目录；文件变化后请点「刷新卡库」。未选择文件夹时，查重范围仍包括内置库和已打开文档。

浏览器预览版可以打开、编辑和下载 `.cdb`，但 Android 专用的库文件夹授权和“导入官方卡库”不可用。

## 主要文件

| 路径 | 作用 |
| --- | --- |
| `www/app.js` | 页面状态、卡片浏览与编辑交互 |
| `www/db-client.js` | 多文档 CDB 读写、查询和导出；基于 `sql.js` |
| `www/cdb.js` | 卡片类型、属性、种族等字段解释 |
| `www/setnames.js` | 系列码中文名称表；公开仓库不包含此生成文件 |
| `www/cards.cdb` | 本地准备的初始卡库；公开仓库不包含此文件 |
| `www/capacitor-bridge.js` | 网页与 Android 文件操作之间的桥接 |
| `android/app/src/main/java/com/ygo/cdbeditor/SaveFilePlugin.java` | Android 系统文件选择、另存为、库文件夹和私有卡库操作 |
| `gen-setnames.js` | 从游戏 `zh-CN/strings.conf` 生成 `www/setnames.js` |
| `BUILD.md` | 环境准备、资源同步与 APK 构建 |

`www/data.js` 仅在卡库加载失败时提供示例数据；示例模式不能保存为完整 `.cdb`。Android 的原生插件在 `MainActivity.java` 注册。打包与运行所需的源文件以 `www/` 和 `android/` 为准，`android/app/src/main/assets/public/` 是同步生成的网页资源副本。
